Cream Audio Player

把喜欢的音乐，放进你的 Notion 里 ♡

① 选择播放器样式

新增四款以你上传的图片为视觉参考，并加入花体英文 Aniseol。配色可通过上方「配色」切换；全部票根与图像模板均支持莫兰迪／洛可可协调主题色。四款新增模板均加入花体英文 Aniseol；现在共有 17 套整体配色可选。

② 添加歌曲（MP3 / M4A 直链）

声纹最大宽度为 560 px、高度 100 px，外层区域高度 130 px。播放时以舒缓、优雅的速度随音乐起伏；保留细碎星辰，背景完全透明、无底板与光晕。请使用可公开访问、能直接播放的音频文件直链（例如 mp3/m4a）。分享页面、登录后才能访问的链接或已失效链接无法播放。跨域音频即使能播放，也可能不允许读取真实频谱；播放器会优先保证声音正常播放。

③ 生成可嵌入的小部件

上传本生成器与 widget.html 后，填入 GitHub Pages 的站点地址。若生成器本身已在线打开，可以点“使用当前站点”。

使用提示

1. 将本文件保存为 index.html，将播放器文件保存为 widget.html，放在同一仓库根目录并发布 GitHub Pages。
2. 生成器会把歌曲配置编码进小部件网址；链接会出现在网址中，不适合机密音频。
3. GitHub Pages 站点通常公开可访问。Notion 私密页面不会自动保护这个外部小部件。
4. 这是纯前端原型，不会把歌曲配置保存到云端；更改歌曲后需重新生成链接。
