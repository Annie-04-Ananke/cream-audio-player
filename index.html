Cream Audio Player

把喜欢的音乐，放进你的 Notion 里 ♡

① 选择播放器样式

黑胶款默认只显示唱片，点击唱片后才显示歌曲信息与播放控制。

② 添加歌曲（MP3 / M4A 直链）

请使用可公开访问、以 http/https 开头的音频直链。普通音乐分享页不一定是音频文件。

③ 生成可嵌入的小部件

上传本生成器与 widget.html 后，填入 GitHub Pages 的站点地址。若生成器本身已在线打开，可以点“使用当前站点”。

使用提示

1. 将本文件保存为 index.html，将播放器文件保存为 widget.html，放在同一仓库根目录并发布 GitHub Pages。
2. 生成器会把歌曲配置编码进小部件网址；链接会出现在网址中，不适合机密音频。
3. GitHub Pages 站点通常公开可访问。Notion 私密页面不会自动保护这个外部小部件。
4. 这是纯前端原型，不会把歌曲配置保存到云端；更改歌曲后需重新生成链接。
